# SOMMET

Entrenador de rodillo para Mac, iPad e iPhone. Te dice qué toca hoy, controla el Wahoo Kickr mientras lo haces con los Zwift Click V2 en las manos y guarda cada sesión (con copia en intervals.icu).

No es un mundo virtual: nada de 3D, avatares ni multijugador.

**Estado:** Fase 0 — definición. Aún no hay código; ver [`docs/`](docs/).
